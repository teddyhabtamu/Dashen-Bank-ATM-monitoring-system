About this page and how health is calculated

Read-only staging. Parsed journals are held for reconciliation and never enter the official atm_transactions table until explicitly promoted. no_receipt sessions are counted as evidence, never turned into transactions.

Healthy — every file for the newest journal date parsed, and that file date is today or yesterday.

Stale — no parse errors, but the newest file is two or more days old. This uses the file-name date, not the last transaction inside it; NCR can keep writing to a file named with an older bank date.

Parse error — at least one file for the newest journal date failed to parse.

No data — no journal file has ever been ingested for this ATM.

Health is current and is not limited by the activity period. It is not an agent-reachability check: an ATM can be Reporting in Fleet onboarding health and still have no new EJ file. An ATM that is out of service, or has had no transactions, can legitimately have no new journal.
